## 🌼 Projects

### 🏥 ICU AKI Prediction
**중환자실 환자의 48시간 이내 급성 신손상(AKI) 발생 위험 예측 및 주요 영향 요인 분석**

> ICU 환자의 임상 데이터를 기반으로 AKI 발생 가능성을 예측하고,  
> SHAP을 활용해 예측 결과에 영향을 미치는 주요 요인을 분석한 프로젝트

| 분석 단계 | 주요 내용 |
|---|---|
| 🧹 **Data Preprocessing** | 임상 데이터의 결측치 및 데이터 특성을 확인하고 모델 학습에 적합하도록 전처리 |
| 📊 **EDA** | 주요 임상 변수의 분포와 AKI 발생 여부에 따른 데이터 특성을 탐색 |
| 🤖 **Predictive Modeling** | XGBoost 기반 분류 모델을 구축하여 48시간 이내 AKI 발생 위험 예측 |
| 📈 **Model Evaluation** | 분류 성능 지표를 활용하여 모델의 예측 성능 평가 |
| 🔍 **Explainable AI** | SHAP을 활용하여 AKI 예측에 영향을 미치는 주요 임상 변수 분석 |
| 🏥 **CDSS 활용** | 예측 결과와 영향 요인을 바탕으로 임상 의사결정을 지원할 수 있는 방향 탐색 |

**Key Features**

- 임상 데이터 전처리 및 예측 변수 구성
- XGBoost 기반 AKI 발생 위험 예측
- SHAP 기반 주요 변수 중요도 및 예측 결과 해석
- 데이터 기반 임상 의사결정 지원 시스템(CDSS) 설계

**Tech Stack:** `Python` `Pandas` `NumPy` `Scikit-learn` `XGBoost` `SHAP` `PostgreSQL`

### 🌷 피부묘기증 CDSS
**피부 이미지와 관련 데이터를 활용한 피부 질환 분석 및 관리 지원 시스템**

> 피부묘기증 관련 데이터를 분석하고 이미지 및 처방 데이터를 활용하여  
> 질환 관리와 의사결정을 지원하는 CDSS 프로젝트

**Key Features**

- 🖼️ VGG16 기반 피부 이미지 특징 및 유사도 분석

- 💊 처방 패턴 분석
